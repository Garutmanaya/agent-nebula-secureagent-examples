# Example 17 — Native A2A Artifacts

Demonstrates application-owned A2A artifacts using only native `a2a-sdk` `TaskUpdater`/`Artifact` behavior. The client verifies artifact IDs, names, Parts, and persistence through the SDK TaskStore with `get_task()`.

```text
make init example-17
make run example-17 server
make run example-17 client
make clean example-17
```
